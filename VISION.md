# harmony runtime — Vision
AI can propose. Humans authorize. Sunsu executes. Evidence proves.

harmony runtime aims to make human–AI collaboration accountable: a shared Madang, a clear Mok, an active Sunsu and a trusted Baton. The goal is to connect intent, authority, execution and evidence without losing who is responsible for each step.

“마지막 토큰 한 개까지, 너의 몫을 다해라”

Personal Cloud, Team Cloud and Independent Server are roadmap directions, all coming soon. This repository currently publishes a development source baseline, not an available hosted service.
